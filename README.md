# AR8 — Blue Rabbit 3D & AR

AR7の操作方針を参考にした独立した3D・ARサイトです。AR7は変更しません。

通常画面ではブルーラビットを360度回転・拡大縮小し、自動回転、視点リセット、3D画像保存ができます。対応スマートフォンでは床・テーブルを検出して現実の空間へモデルを配置します。

## AR方式

- Android: Scene Viewerを優先し、必要に応じてWebXRへ対応します。ARCore対応端末とGoogleのAR関連サービスが必要です。
- iPhone / iPad: SafariからAR Quick Lookを起動します。GLBからUSDZを端末上で生成します。
- 非対応端末: 通常の3D表示に対応します。

HTTPSで公開してください。GitHub Pagesのmainブランチのルートを公開先に設定します。

Amazonの「空間に置いて確認する」操作を参考にしています。Amazon独自のアプリやコードを使用した実装ではありません。

## モデルと依存ライブラリ

`assets/blue-rabbit.glb` はユーザーの参照キャラクターから作成した、背景なし・ポーズ固定の立体モデルです。

`vendor/model-viewer.min.js` は公式 `@google/model-viewer` 4.3.1（Apache-2.0）です。ライセンスは同ディレクトリに保存しています。

カメラ映像はサーバーへ送信しません。ARの権限・表示・撮影操作は端末のブラウザまたはネイティブAR画面で処理します。

## 検証

ブラウザの3D表示、GLBの読込、回転／拡大縮小／リセット、モデルの背景がないことを検証します。AR実空間への配置は、対応iPhone／Android実機で確認が必要です。
